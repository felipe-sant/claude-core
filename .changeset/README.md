# Notas de mudança

Todo pull request traz uma nota de mudança nesta pasta. Rode `npm run changeset` e escolha o tipo (major, minor ou patch), ou `npm run changeset -- --empty` quando a mudança for só de documentação, CI ou testes.

O texto da nota fica em português simples. A regra de versão e o fluxo completo estão no `README.md` da raiz.
